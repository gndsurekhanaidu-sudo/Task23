# Task23
Value Counts and Frequency Analysis

Project Overview

This project focuses on analyzing categorical data using Python and Pandas. It uses the "value_counts()" function to calculate frequencies, proportions, and percentage distributions of different categories.

Objective

- Understand categorical data.
- Calculate frequency counts using "value_counts()".
- Calculate proportions using "normalize=True".
- Convert proportions into percentages.
- Visualize categorical distributions.

Tools and Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

Dataset

A sample dataset was created using Python without requiring an external CSV file.

The dataset contains five categorical columns:

1. Gender
2. Department
3. City
4. Grade
5. Status

Tasks Performed

1. Imported Pandas and Matplotlib libraries.
2. Created a sample dataset.
3. Performed frequency analysis on five categorical columns.
4. Calculated proportions using "normalize=True".
5. Calculated percentage distributions.
6. Visualized categorical data using a bar chart.

Key Functions Used

- "pd.DataFrame()" – Creates a DataFrame.
- "value_counts()" – Counts the occurrences of each category.
- "value_counts(normalize=True)" – Calculates proportions.
- "plot(kind='bar')" – Creates a bar chart.
- "plt.show()" – Displays the chart.

Results and Interpretation

- Male appears more frequently than Female.
- Grade A is the most frequently occurring grade.
- Pass status appears more frequently than Fail.
- Frequency and percentage analysis help understand categorical data distributions.

Conclusion

This task helped me understand how to analyze categorical columns using Pandas. I learned to calculate frequencies, proportions, and percentages and visualize categorical data using bar charts.
